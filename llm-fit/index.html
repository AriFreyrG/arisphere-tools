    Models

      How the estimate works

      A model fits when its weights at the chosen quantization, plus the cache for the context length and a little working space, fit in the memory the device can give it.

      Speed is estimated from memory bandwidth: writing each word means reading the model's active weights once, so bandwidth divided by that size gives tokens per second. Real speeds depend on the app (llama.cpp, LM Studio, Ollama, MLX) and are often within about 30% of this. Reading a long prompt first takes extra time.

      Mixture-of-experts models (marked MoE) need memory for all their weights but only read a few experts per token, so they are much faster than their size suggests.
